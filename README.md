# @sles1401 — Instagram Story Highlight Studio

Interactive design studio and PNG assets (`1080×1920 px`) for `@sles1401` Instagram Story Highlights with a warm analog aesthetic.

## Contents

- `index.html` — Interactive HTML5 Canvas Studio for **About / Start** and **Notes / Learn** (with live text editor & 1-click PNG export).
- `render_notes.ps1` — PowerShell (`System.Drawing`) renderer for `Notes / Learn` slides.
- `render_work.ps1` — PowerShell (`System.Drawing`) renderer for `Work / QA` slides.
- `exports/` — Ready-to-upload `1080×1920 px` PNGs for `Notes / Learn` and `Work / QA`.
